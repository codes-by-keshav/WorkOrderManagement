# Blockchain Based Work Order Management Project

This project is a cutting-edge blockchain-powered platform that revolutionizes how work orders, certificates, and auctions are managed. With a robust Go backend and a sleek, responsive React frontend, it ensures tamper-proof records, real-time transparency, and decentralized control—perfect for industries demanding trust, traceability, and automation.

From issuing verifiable certificates to hosting trustless auctions and automating work order flows, this system brings the power of Web3 to real-world operations with blazing efficiency and rock-solid reliability.

## Getting Started

### Prerequisites

- Go (version 1.15 or later)
- Node.js (version 14 or later)
- npm (usually comes with Node.js)

### Backend Setup

1. Navigate to the backend directory:
2. Run the Go server  using : `go run .`

The server will start on `http://localhost:8080`.

### Frontend Setup

1. Navigate to the frontend directory:
2. Install dependencies using `npm install`
3. Start the React app using `npm start`

The app will be available at `http://localhost:3000`.

---

## Usage

1. Start the Go server first.
2. Then start the React app.
3. Open a web browser and go to `http://localhost:3000`.
4. Use the various features available in the application.
